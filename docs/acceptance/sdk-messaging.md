# Проверка SDK-восстановления — Workflow Pilot 0.5.39

[Контракт](../modules/sdk-messaging.md). Автоматические доказательства и живая приёмка разделены. Режима активации и внешнего скрипта нет.

## Автоматические доказательства

IDENTITY/DELIVERY/PROOF/VERSION плана sdk-recovery-identity сохраняют checks и SHA в Git/Kit. Пройдены unit-all, electron-smoke, architecture, executor-channel, codex-tools-live, обе части kit-check/kit-assignments, kit-upgrade и release-tooling. DOCS не перезапускает suite и не является его доказательством.

| Область | Проверенное свойство |
| --- | --- |
| Identity | Устойчивый workspaceId; одинаковые имена, общий projectId worktree, повторное создание пути, restart миграции; чужая история/выбор/grant не наследуются |
| Review → выбор | Отказ уведомления Review не удерживает следующий выбор; решение сохранено один раз, доступно чтение актуальных входящих |
| Настоящий SDK fixture | JSON-RPC rejection, isError, timeout и поздний ответ проходят через закреплённый SDK, HTML-панель и MCP; сохраняются безопасный код/стадия, один message_id и отдельные attempts |
| Recovery | Бюджет трёх попыток переживает restart; две панели, late report и read не создают нового поручения; уже обработанный вход не возвращает исполнительный контекст |
| Полномочия | Stop/grant/identity/stale и неизвестный legacy-эффект не обходятся; постоянный отказ заканчивает автоматические попытки |
| Полный цикл | Пять параллельных E, injected SDK-ошибка result, двусторонний обмен, зависимая задача, DOCS, acceptance точных SHA, интеграции и cleanup/complete без повторных эффектов |
| История | До и после публикации плана видны attempts текущего workspace; сохранение, SDK accepted и MCP read различимы |
| Upgrade | Неизменяемые выпущенные Kit 1.10.1/1.10.2/1.10.3 переходят на 1.10.4/роли 13 с сохранением байтов плана |
| Версии | Package/backend/build/protocol согласованы; новый протокол панели 7 явно отвергает несовместимый iframe |

Fixtures используют временные проекты и подставленного хоста ChatGPT; модельные команды и рабочие профили не запускаются. Поздний ответ после тайм-аута может быть проигнорирован самим SDK: проверка подтверждает корреляцию и безопасное восстановление, не выдумывая accepted. Один предварительный Electron smoke завершился тайм-аутом bootstrap; отдельный повтор и полный обязательный прогон прошли. В fixture добавлена диагностика ошибки; первопричина того единичного тайм-аута не установлена.

## Живая приёмка

В 0.5.38 реальное уведомление Review получило SDK_ERROR, а UNKNOWN удержал выбор оркестрации. Точные детали исключения прежний catch не сохранил. Исправлены восстановление/диагностика и изоляция, но устранение первопричины того исключения не заявляется.

| Проверка 0.5.39 | Статус |
| --- | --- |
| Настоящий ChatGPT: Review, выбор, занятой O/E, несколько входящих и полный цикл | NOT_RUN |
| Новая служба macOS с реальными чатами и восстановлением | NOT_RUN |
| Native Windows/Linux, clean install/VM | NOT_RUN |
| iPad/HTTP/Tailscale | NOT_RUN |

Поставка трёх ОС, подпись/состав/хеши, локальная установка либо verified pending и GitHub проверяются отдельными delivery-задачами после DOCS. Manifest, Kit evidence и опубликованный комплект подтверждают только соответствующую стадию. Запуск нового backend и пользовательская приёмка не следуют из наличия пакета или pending-копии.
