NAME001 / EXEC003. Автоматические проверки выполнены на изолированных fixtures без моделей, рабочего профиля, Test_003 и донора. Коммиты CHOICE/NAME/PROOF/VERSION сохраняют доказательства соответствующих suite; DOCS не запускает application tests. Сборка, установка и GitHub подтверждаются отдельно delivery-задачами и release-manifest.json.

## Автоматическая граница

PASS: все три варианта выбора через настоящий MCP, долговечное нажатие отдельно от доставки/read; старый accepted/read UI-gate, scope=null и текущий scope, UNKNOWN/unread и настоящие assignment barriers. Длительный сценарий ускоряет часы на пять минут без реального ожидания: read UI-события не запускает probes конца ответа. Единственное позднее изменение через BrowserSessions/PageStateSource продолжает очередь; завершение локальной команды через штатный watcher доставляет второй результат без нового изменения страницы.

Связный API/MCP/SDK/Kit/Git fixture проходит Review OFF→ON/read → раннее имя → выбор orchestrated → длительную подготовку и два раунда Review → публикацию → один Start → T001/T002 → read O → acceptance точных SHA → интеграции → T003 → DOCS → terminal receipts → cleanup/complete. Сохранённое UI-событие текущего scope имеет read=true и reply_observed=false и не мешает complete. Node suite, Electron smoke, MCP/каталог, архитектура, обе части Kit и upgrade назначены соответствующим задачам, без ослабления проверок.

PASS раннего имени: Python MCP/bridge → backend/store → настоящий renderer до плана, title sync, защита manual/scope, другой выбранный проект, restart, поздний page-title и ошибки записи/identity. Старый validator 0.5.35 и выпущенный Kit 1.10.1 — неизменяемые fixtures; их происхождение и SHA сохранены в репозитории. Это не доказательство живого поведения ChatGPT или native Windows/Linux.
