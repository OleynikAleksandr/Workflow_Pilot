# Старт службы и записи исполнителей (0.4.5)

Временная спецификация 0.4.5; после выпуска переносится в docs/modules/backend.md и docs/modules/project-lifecycle.md.

1. Проект, чьё состояние транзакции Kit нельзя прочитать (нет папки, битый git или worktree), не останавливает старт службы; незавершённая транзакция Kit останавливает (`BACKEND_KIT_TRANSACTION_PENDING`).
2. «Убрать из списка» и удаление проекта убирают записи всех его исполнителей, даже без найденного worktree; при «Убрать из списка» папки не трогаются.

Причина: служба 0.4.4 падала при старте из-за worktree исполнителя удалённого проекта WP_0.4.0_Test.
