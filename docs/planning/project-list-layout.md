# Строка списка проектов (0.4.6)

Временная спецификация 0.4.6; после выпуска переносится в docs/modules/desktop.md.

В 0.4.5 кнопка «В архив» в строке списка проектов унаследовала `width:100%` от общего правила меню и заняла всю строку: название проекта сжалось и выводилось по одной букве в столбик.

1. Строка списка проектов: название проекта занимает всю свободную ширину и переносится только по словам; «В архив» — компактная кнопка по ширине текста справа.
2. Electron smoke проверяет раскладку на настоящей боковой панели: ширина названия больше ширины «В архив», высота строки не больше трёх строк текста.
