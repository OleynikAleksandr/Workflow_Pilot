# Одна кнопка выполнения плана (0.4.4)

Временная спецификация выпуска 0.4.4. После выпуска действующее содержание переносится в docs/modules/orchestrated-execution.md, docs/modules/workflow-execution.md и docs/modules/desktop.md, документ удаляется.

## Проблема

В 0.4.3 кнопка «Включить автовыполнение» (AutoPlan) скрывалась только у активного плана оркестратора: её было видно до публикации плана, после его выполнения и у прежних планов. Пользователь решил: AutoPlan как отдельной функции и кнопки нет; у плана одна кнопка, кроме Review, — «Начать выполнение плана» / «Пауза» / «Продолжить».

## Требования

1. Кнопки и канала включения AutoPlan нет: из боковой панели удалены переключатель и его сообщения, из preload и `DESKTOP_CHANNELS` — `setAutoPlan` / `pilot:auto-plan`.
2. Одна кнопка показывается у любого активного плана (ACTIVE/BLOCKED) с незавершёнными задачами, кроме внешней сессии плагина. Без плана, во время планирования и после выполнения кнопки нет.
3. План оркестратора — без изменений (ExecutionControl: запуск, пауза после завершения исполнителей, продолжение).
4. Прежний план (sequential/parallel) запускается той же кнопкой: «Начать» и «Продолжить» включают прежний механизм продолжений этого плана с его проверками, «Пауза» выключает его сразу (текущий ответ ChatGPT завершается, новые сообщения не отправляются). Состояние кнопки прежнего плана берётся из этого механизма: работает — «Пауза», остановлен после запуска — «Продолжить», ни разу не запускался — «Начать выполнение плана».
5. Команды API `plan.continue` и `plan.stop` запускают и ставят на паузу план той же кнопкой.
6. Тексты состояний не упоминают «автовыполнение»: говорится о выполнении плана.

## Проверки

- Unit: кнопка запускает и ставит на паузу прежний план; состояние кнопки прежнего плана; план оркестратора — прежняя модель; канала `pilot:auto-plan` нет.
- `sidebar`: переключателя AutoPlan нет; одна кнопка у прежнего и у оркестрованного плана; без плана кнопки нет.
- Electron smoke проходит прежние сценарии через кнопку плана.
- Живую проверку выполняет пользователь.

## Запись проекта без папки

Найдено: папка Test_WF001 очищена на диске, запись осталась. Выбор такого проекта падает при чтении его состояния, а «Перенести в архив» есть только в меню выбранного проекта — запись нельзя было убрать.

7. В списке проектов (выбор проекта) у каждой записи есть действие «Перенести в архив», не требующее выбора проекта и чтения папки; для проекта с активным планом действует то же подтверждение. Из архива запись убирается штатно: «Убрать из списка» (папка не трогается) или «Удалить с диска» (для отсутствующей папки удаляется только запись).
