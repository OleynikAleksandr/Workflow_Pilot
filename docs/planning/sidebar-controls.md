# Уточнение управляющих элементов sidebar

Поручение пользователя после проверки 0.5.34: убрать кнопку «Текущие действия», которая открывает копию основной панели Workflow Pilot. Не переносить её в меню, не создавать замену или новый способ отображения без обсуждения. Будущий переход от Electron/sidebar к панели — направление обсуждения, не поручение реализации.

Записанное исправление: удалить кнопку и всё связанное с её дублирующей клиентской областью: dialog-копию, обработчики, клиентские IPC/preload/HTTP-ветки представления. В новом Chat/проекте, до и после публикации плана, её нет. Основная MCP-панель и нужные ей общие компоненты, навигация и одна кнопка выполнения опубликованного плана сохраняются. Согласовать существующие тесты; скрытый вспомогательный компонент не выдавать за доступный пользователю путь.

Пользователь уточнил: Review оставить на прежнем месте и без изменений. Его дальнейшее размещение обсудим отдельно. Первоначальное предложение скрывать переключатель отменено.

Последнее поручение — пока записать согласованное исправление в Desktop-журнал замечаний. Начатая локальная правка отложена, функциональных изменений в checkout не оставлено. Реализация и проверки не выполнены; задача не DONE. Новый выпуск, установка и публикация не поручены. При реализации проверки: unit-all, electron-smoke и architecture через Kit. Действующие модульные контракты до нового выпуска продолжают описывать 0.5.34.
