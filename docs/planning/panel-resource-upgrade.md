# Обновление ресурса панели

19.10.2026 пользователь поручил дополнить текущий план исправлением повторного открытия панели 0.5.2 в установленном Workflow Pilot 0.5.5, собрать и опубликовать новый выпуск. Реализация продолжается здесь одним агентом. Живые модели и управление окнами не входят в автоматические проверки.

## Установленные факты

В установленном bundle, runtime source и свежем resources/read одинаковый HTML 0.5.5-communication-2. В новом разговоре зарегистрирован оркестратор, но нет привязки панели; пользователь видит HTML 0.5.2-communication-1. В обоих выпусках инструмент использует один ui://workflow-pilot/projects-v1.html. Точное хранилище показанной старой копии хостом не раскрыто.

OpenAI определяет URI ресурса как ключ кэша и требует нового URI при несовместимом изменении HTML/JS/CSS: https://developers.openai.com/plugins/build/chatgpt-ui#embed-the-component-in-the-server-response . Обновление каталога не гарантирует замену содержимого прежнего ключа.

## Изменение

- URI текущей панели вычисляется из SHA-256 полного выдаваемого HTML. Инструмент и ресурс получают один неизменяемый снимок при запуске MCP. Изменение файла после регистрации не меняет содержимое уже объявленного URI; следующий запуск получает новый адрес.
- Прежний projects-v1.html сохраняется только как безопасное сообщение о переходе, без регистрации, разрешения и отправок. Новые вызовы инструмента используют исключительно новый адрес. Уже закэшированный старый HTML нельзя считать обновлённым серверной заменой.
- Проверка протокола/build остаётся строгой. Ошибка показывает фактическую и ожидаемую версии и понятные действия: обновить инструменты подключения и выполнить новый вызов панели. Перезапуск приложения сам по себе не объявляется решением кэша хоста.
- Регрессионный host хранит старый ресурс под старым ключом, обновляет каталог настоящего MCP, загружает новую панель через объявленный URI и проверяет автоматическую привязку без ручного join/ID/Enable. Проверяется неизменность снимка, смена URI при изменении HTML/JS/CSS и отказ небезопасного смешения версий.
- Сборка проверяет согласованность HTML/build/protocol, ресурсного контракта MCP и комплекта. Следующий свободный выпуск 0.5.6; Kit остаётся 1.8.2, его исходники не меняются.

## Поставка и приёмка

DOCS-2 переносит действующий контракт и сведения о выявленном отказе в документы модулей, удаляет эту временную спецификацию. Затем отдельные RELEASE-2, INSTALL-2, PUBLISH-2: три платформы из одного sourceCommit, штатная установка готового macOS bundle и GitHub Release с проверкой assets. Перед production build удаляются только проверенные Python-кэши tools/codex-app-server-mcp. Работающие приложение и служба не останавливаются; допустим подтверждённый pending установки.

Автоматическая регрессия не доказывает обновление реальным ChatGPT. После выпуска пользователь обновляет каталог плагина, выполняет свежий вызов панели и подтверждает новый build и автоматическую привязку O. Затем возобновляются S1–S3. Очистка профиля, cookies и истории не является штатной частью исправления.
