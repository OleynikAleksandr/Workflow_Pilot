# Обновление ресурса панели

19.10.2026 пользователь поручил дополнить текущий план исправлением старой панели и выпуском 0.5.6. Работа продолжается одним агентом; Kit остаётся 1.8.2. Окна и службы пользователя не трогать.

## Причина и контракт

Bundle, runtime и свежий MCP resources/read выдают 0.5.5, но пользователь видит панель 0.5.2. О зарегистрирован, привязки панели нет. Адрес projects-v1.html одинаков; точное хранилище старой копии не установлено. По [OpenAI](https://developers.openai.com/plugins/build/chatgpt-ui#embed-the-component-in-the-server-response) URI является ключом кэша.

- URI = SHA-256 полного HTML. Каталог и resources/read используют неизменяемый снимок при регистрации MCP; изменение файла влияет только на следующий запуск.
- Прежний URI возвращает только сообщение перехода без SDK/отправок. Новые вызовы используют новый URI; уже сохранённая старая панель сама не заменяется.
- Строгий контроль build/protocol сохраняется. Ошибка показывает обе версии и требует обновить инструменты ChatGPT и заново вызвать панель; переустановка приложения не объявляется очисткой кэша.
- Настоящие MCP/SDK в изоляции проверяют старый кэш, новый каталог, автоматическую привязку O без join/ID/Enable, смену URI для HTML/CSS/JS и неизменность снимка. Упаковка проверяет HTML, compiled build, протокол и версию приложения.

## Завершение

DOCS-2 переносит контракт в модули и удаляет эту спецификацию. RELEASE-2 → INSTALL-2 → PUBLISH-2: три ОС из одного sourceCommit, очистка проверенных Python-кэшей, штатная установка готового bundle (при живой службе — pending), GitHub с проверкой assets. Подробные критерии сохранены в задачах.

Живой PASS не выводится из fixtures. Пользователь проверяет новый build и привязку O после обновления инструментов и свежего вызова, затем S1–S3. Профиль, cookies и история не очищаются.
