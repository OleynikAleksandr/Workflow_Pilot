# Краткая архитектура Workflow Pilot

## Назначение и текущее состояние

Workflow Pilot — самостоятельное настольное приложение для управления проектами и работой с агентами через ChatGPT Web. Репозиторий: https://github.com/OleynikAleksandr/Workflow_Pilot.

Перенесена исходная база приложения 0.1.0 с собственной identity; установленный Workflow Kit 1.7.2 сохранён. Существующие модули пока преимущественно находятся в донорской раскладке, разделение по фасадам продолжается следующими задачами. Первый общий выпуск планируется для macOS arm64, Windows x64 и Ubuntu 24.04 LTS x64 (X11); Linux-адаптер и полный комплект ещё в работе. Донор — Project Web Pilot 0.6.115; его код и пользовательское окружение не изменяются.

## Планируемое устройство

Control владеет проектами, сессиями, привязками и продуктовой координацией; Workflow Kit остаётся владельцем current plan и транзакций. Execution выполняет команды, операции с файлами, ведёт службы и браузер. Frontend показывает состояние и передаёт действия через ControlFacade. Desktop bootstrap собирает конкретные зависимости.

AutoPlan, Review, sequential/parallel и оба канала подключения сохраняются в первом выпуске. Новая логика оркестратора — отдельный следующий этап.

## Запуск и проверка

Node 24.21.0, Electron 44.5.1: npm ci и npm start. Собственные профиль, браузер, runtime и службы исключают автоматическое наследование донора. npm test и npm run smoke проверяют перенесённую базу в fixtures; Python для executor fixtures находится в .harness/runtime/test-python. Команда build перенесена, но выпуск выполняется только после DOCS и завершения трёх платформ. Реальный интерфейс и VM проверяет пользователь; автоматические окна скрыты, системный clipboard не используется.
