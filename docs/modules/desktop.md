# Desktop — текущая база

Smoke работает в скрытых окнах, без их показа/фокусировки/перемещения, с буфером обмена в памяти. Browser clipboard в fixture направлен в локальный protocol handler. Тесты проверяют обмен данными и IPC, а нативный системный clipboard проверяет пользователь при живой приёмке. Синтетические события адресуются только изолированному тестовому renderer, не мыши/клавиатуре ОС.

package workflow-pilot, product Workflow Pilot, версия 0.1.0; Node 24.21.0 и Electron 44.5.1. npm start входит через src/main.mjs; frontend/desktop/bootstrap.mjs устанавливает собственные userData/sessionData до конструирования stores и браузера, отказывает при profile symlink. Окна/IPC пока сохраняют исходное размещение; полное выделение Frontend — T008.

Первый запуск сохраняет мастер ChatGPT, компонентов, туннеля/ID, подключения и проекта. Для нового продукта используются собственные службы и имя подключения Workflow Pilot Local Mac/Windows. Системные подтверждения и живой интерфейс проверяет пользователь.

Сгенерированные Kit/observer, app, временные установки, runtime и npm/Python caches исключены из Git. Скрипты сборки переименованы для нового продукта, но production build запрещён до DOCS/T012. Конфиг подписи донора не переносился; окончательный режим подписи и три платформы завершает T010.
