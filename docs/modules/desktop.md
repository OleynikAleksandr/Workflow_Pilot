# Desktop

Identity: package workflow-pilot, product Workflow Pilot, bundle com.oleynik.WorkflowPilot. Свои userData/browser/runtime/службы обязательны. Старые профили, cookies, app-state и подпись не импортируются. Формат существующих session ID и внешние DOM-контракты сохраняются; имена каталогов/служб нового продукта — собственные.

`npm start` входит через `src/main.mjs`. `frontend/desktop/bootstrap.mjs` устанавливает собственные userData/sessionData, отказывает при symlink профиля и собирает Control, Execution и зависимости оболочки. `application.mjs` размещает Chromium и sidebar в одном основном окне, обрабатывает нативные диалоги и публикует снимки для renderer. Архив и редактор цветов сохраняют отдельные вспомогательные окна.

UI, preload, IPC и вспомогательные окна расположены в `src/frontend/desktop/`. Старые копии UI/preload удалены. Renderer импортирует только локальный UI и contracts. Desktop обращается к Control через фасад; конкретные реализации Execution подключает bootstrap. Architecture gate запрещает обход этих границ и корневые re-export внутри Frontend.

Каждая IPC-возможность входит в фиксированный список. До вызова действия проверяются точные webContents, главный frame и URL локальной страницы. У удалённых страниц ChatGPT нет локального preload. Редактор цветов использует ту же проверку источника. На закрытии освобождаются обработчики IPC; renderer освобождает подписки состояния при pagehide. BrowserHost предоставляет Execution/browser место для WebContentsView.

Control владеет настройками и сериализует запись через Execution/files. Снимки отделены от внутреннего состояния. Неудачная запись не меняет принятые настройки; следующая запись может продолжить очередь. Быстрые изменения отдельных цветов объединяются внутри очереди, сохраняя остальные поля. Полный сброс палитры остаётся отдельной операцией. Текущий план и транзакции принадлежат только Kit.

Связанные сценарии: [первый запуск](first-run-onboarding.md), [проекты и архив](project-lifecycle.md), [Control](control.md), [браузер](browser.md).

Проверки: desktop-boundaries проверяет запреты IPC, фиксированные preload-возможности, освобождение подписок, запись настроек/отказ/restart и отсутствие секретов в runtime DTO. Electron smoke проверяет реальные IPC-пути и Chromium в скрытых fixture-окнах, без показа, фокусировки и управления окнами ОС. Clipboard находится в памяти; системные службы и профиль пользователя не изменяются.

Исходный UI доступен для ручной проверки Mac через `npm start`. Живые вход в ChatGPT, системные разрешения, clipboard и подключение проверяет пользователь. Production build выполняется после DOCS; подпись и полный комплект платформ завершаются отдельно. Сгенерированные Kit/observer и runtime не входят в Git.
