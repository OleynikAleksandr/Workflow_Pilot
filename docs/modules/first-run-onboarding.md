# Первый запуск и подключения

Мастер расположен в `frontend/desktop/ui/startup.mjs`. Control/startup хранит готовность компьютера, наблюдаемое состояние входа ChatGPT и шаг подключения. Execution проверяет/подготавливает компоненты, выполняет платформенные команды и обслуживает Secure MCP Tunnel/VPS. Desktop предоставляет нативные подтверждения, ввод и отображение. ControlFacade создаёт единственный startup flow и связанный обработчик ввода туннеля.

Пользователь входит или регистрируется на странице ChatGPT самостоятельно. Готовность аккаунта возникает из наблюдения страницы; загрузка, ошибка и устаревшее поколение страницы не подтверждают вход. Подготовка компьютера сохраняет исходные шаги проверки Node/Git, установки компонентов и локального MCP. Ограниченный watcher установки Git и наблюдение clipboard действуют только в прежних условиях; новых фоновых опросов нет, при завершении подписки и таймеры освобождаются.

Secure MCP Tunnel использует собственные ID и ключ пользователя. Мастер принимает ID через явный ввод либо изменение clipboard во время активного шага; старое содержимое clipboard не принимается как новые данные. Затем пользователь предоставляет ключ, а готовность подтверждает runtime. Настройка не имитирует системные подтверждения, регистрацию, выдачу ключа или добавление коннектора ChatGPT.

В публичные снимки входят только шаг, готовность и безопасные сообщения. Ключ, аргументы команд и полный путь коннектора не передаются renderer. VPS DTO формируется по разрешённым полям: адрес маскируется, сырой stderr/ошибка заменяются понятным сообщением. Полный адрес коннектора копируется отдельным действием пользователя непосредственно в clipboard.

Собственный VPS пока не настроен. Без собственного route.json отображаются `setup-required` и предложение использовать Secure MCP Tunnel. Готовые конфигурации, службы, ключи и профиль донора не захватываются. Настройка серверного маршрута не входит в текущий перенос. Локальное приложение может использовать собственный Secure MCP Tunnel без VPS.

Автоматические тесты подставляют проверки компонентов, runtime и clipboard; они не устанавливают реальные службы и не выполняют действия аккаунта пользователя. Ручная приёмка Mac: открыть приложение, пройти вход ChatGPT, подготовить компьютер, настроить свой туннель и коннектор, открыть проект и начать новую сессию. Эта живая проверка остаётся за пользователем. Linux first-run реализуется следующей задачей.
