# Workflow Pilot

Настольное приложение: локальные проекты, планы и сессии ChatGPT Web. Chat и Work используют веб-аккаунт ChatGPT; локальные файлы и команды доступны через собственный MCP-исполнитель, без модельных запросов к OpenAI API. С 0.2.0 работа идёт в фоновой службе: окно можно закрыть, а план, ChatGPT, MCP и туннель продолжат работать. С 0.3.0 тот же интерфейс открывается на iPad из любой точки интернета через вашу сеть Tailscale.

## Версия и готовность

Версия исходников 0.4.7, Electron 44.5.1, Node 24.21.0, Workflow Kit 1.8.1. С 0.2.0 — [независимый backend](docs/modules/backend.md): одна фоновая служба владеет страницами ChatGPT, проектами, выполнением планов и Review, MCP, туннелем и мостом [плагина ChatGPT](docs/modules/chatgpt-plugin.md); окно — отдельный клиент, показывающий интерактивное изображение той же страницы. 0.2.1 исправляет найденное при первом живом запуске: страница ChatGPT, чей процесс завершился, перезагружается сама без повторной отправки; окно не застревает в режиме наблюдения; переключение сессий большого проекта больше не даёт ошибку протокола; фоновая служба не получает отдельную иконку в Dock; добавлены журналы диагностики `backend-events.jsonl` и `client-events.jsonl`. 0.3.0 добавляет [доступ с iPad через Tailscale](docs/modules/remote-access.md): необязательный шаг мастера и раздел Настроек проводят по шагам на компьютере и на iPad; устройство подтверждается кодом на компьютере. 0.3.1 исправляет чтение состояния Tailscale фоновой службой и подсказывает бесплатный личный аккаунт. Автоматические проверки пройдены на fixtures; [живая приёмка Mac](docs/acceptance/backend-independence.md) ожидает пользователя. Состав готового комплекта подтверждает `release-manifest.json`; GitHub-публикация выполняется отдельно.

С 0.4.0 — [оркестрованное выполнение](docs/modules/orchestrated-execution.md): новая сессия проекта без плана становится оркестратором, готовит спецификацию и план, микрозадачи выполняют отдельные исполнители в своих worktree, а план ведёт одна кнопка «Начать выполнение плана» / «Пауза» / «Продолжить» до выпуска и очистки. С 0.4.4 у любого плана, включая начатые sequential/parallel-планы базы 0.6.115, одна кнопка «Начать выполнение плана» / «Пауза» / «Продолжить» (и Review); других переключателей запуска нет. 0.4.1 исправляет ввод в изображение страницы ChatGPT: вставка текста (Cmd+V, меню), контекстное меню по правой кнопке, перетаскивание файлов и вставка картинок из буфера ([клиент](docs/modules/desktop.md)). 0.4.2 исправляет найденное при первой живой приёмке оркестратора: исполнитель запускается кнопкой плана и всегда в режиме Chat; выбор задачи в to-do plan меняет только диалог справа, клик по оркестратору возвращает его диалог; окно восстанавливается после разрыва потока; остановка службы не ждёт неотправленную подготовку контекста. 0.4.3: проект с активным планом можно перенести в архив и затем удалить после подтверждения (выполнение плана останавливается, план в Kit сохраняется); исполнитель, которому ещё ничего не отправлено, после перезапуска открывается заново в Chat и получает задачу. 0.4.4: одна кнопка выполнения у всех планов, переключателя автовыполнения нет; любой проект из списка можно перенести в архив без выбора, в том числе запись с удалённой папкой. 0.4.5: битый или удалённый проект больше не мешает старту фоновой службы, удаление проекта убирает записи его исполнителей. 0.4.6: в списке проектов название снова выводится в строку, «В архив» — компактная кнопка справа. 0.4.7: Workflow Kit 1.8.1 больше не упоминает AutoPlan в инструкциях агенту — запуск, пауза и продолжение плана только кнопкой пользователя; механизм продолжения прежних планов в коде переименован (настройки прежних версий переносятся сами); названия задач в to-do plan переносятся по ширине панели, переключение сессий не дёргает окно. [Следующие этапы backend](docs/planning/backend-independence-followup.md) относятся к отдельным планам. [Происхождение и лицензия](PROVENANCE.md).

## Установка и запуск

На macOS arm64 установите Node 24.21.0 и Git, затем из корня проекта:

```bash
npm ci
npm start
```

Prestart подготавливает Kit, observer и HTML плагина. `npm start` открывает клиент; если фоновая служба не запущена, клиент запускает её сам. Используется собственный профиль `~/Library/Application Support/Workflow Pilot` (профиль 0.1.6 подходит без изменений). Пройдите [мастер](docs/modules/first-run-onboarding.md): самостоятельный вход/регистрация ChatGPT, подготовка компьютера, свой Secure MCP Tunnel и коннектор. VPS требует отдельного собственного маршрута; без него отображается необходимость настройки. Ключи, cookies и службы донора не импортируются.

Для существующего проекта выберите папку, проверьте предложение Kit, создайте новую Chat/Work-сессию и отправьте recovery. Прежде прекратите исполнение этого же плана в другом приложении. [Совместимость старых проектов](docs/modules/project-compatibility.md).

**Окно и фоновая служба.** «Закрыть окно (работа продолжится в фоне)», Cmd+Q и закрытие окна завершают только клиент. Состояние службы показывает значок в строке меню; повторное открытие Workflow Pilot (Dock, Finder, Spotlight или значок → «Открыть Workflow Pilot») возвращает к той же странице. Чтобы остановить всё, выберите значок → «Остановить фоновую службу…» или то же в меню Workflow Pilot: новые отправки прекратятся, текущий ответ ChatGPT, инструменты и команды Kit завершатся, затем служба выйдет. Остановку во время ожидания можно отменить; принудительного завершения нет. Без системного tray (часть Linux-окружений) статус и остановка доступны в меню клиента. Одновременно управляет одно окно; другие наблюдают, пока управление не взято явно.

**iPad из любой точки интернета.** Настройки → «Доступ с iPad и других устройств» (или шаг «+ Доступ с iPad» в мастере). Tailscale бесплатен для личного использования (тариф Personal); входите личным аккаунтом Google, Apple или GitHub, не рабочей почтой на собственном домене — она создаёт платную сеть организации. На компьютере: установите Tailscale, войдите, один раз разрешите HTTPS в панели Tailscale (DNS → HTTPS Certificates) и нажмите «Включить доступ с других устройств». На iPad: установите Tailscale из App Store тем же аккаунтом, откройте показанный адрес в Safari (или QR-код), подтвердите код на компьютере. Доступ работает только внутри вашей сети Tailscale, без публичного адреса; пока он включён, компьютер не засыпает.

**Готовый комплект и обновление.** Комплект находится в `~/Downloads/WorkflowPilot-<version>`; распакуйте пакет своей платформы и следуйте INSTALL.txt. После каждого выпуска штатный installer обновляет `/Applications/Workflow Pilot.app` и собственную копию в корне проекта без пересборки; он не закрывает и не перезапускает приложение. Переход с 0.1.6: полностью завершите 0.1.6 и откройте новую копию из Applications. Переход с 0.2.0 и новее: закрытия окна недостаточно — остановите фоновую службу (значок или меню), дождитесь её выхода и откройте новую версию. Если служба работала во время установки, installer оставил проверенную копию в ожидании: после остановки службы повторите установку. Клиент новой версии, подключившийся к старой службе, только объясняет переход. Подробности — [контракт поставки](docs/modules/release.md); Linux-зависимости — [Linux runtime](docs/modules/linux.md).

## Проверки

Для ChatGPT Desktop после запуска новой версии откройте существующее подключение в [ChatGPT Plugins](https://chatgpt.com/plugins), нажмите **Refresh**, затем выберите плагин через `@` в новом разговоре. Попросите показать панель Workflow Pilot, выберите проект и нажмите «Новая сессия». Плагин работает и при закрытом окне Workflow Pilot, пока запущена фоновая служба. Полная [инструкция и матрица проверки](docs/modules/chatgpt-plugin.md) включают прямую привязку уже открытого разговора и запуск нового чата из меню проекта через подготовленную панель.

```bash
npm test
npm run smoke
npm run check:architecture
npm run check --prefix packages/workflow-kit
node --test tests/codex-app-server-mcp.test.mjs
npm run check:codex-tools
```

Unit suite использует четыре процесса и включает backend-тесты на временных профилях с локальной fixture-страницей вместо ChatGPT. Smoke запускает скрытый in-process стенд разработки с изолированными Chromium fixtures. Executor fixtures используют настоящий Codex App Server без модельных ходов; Python-среда тестов — .harness/runtime/test-python (Python 3.13.9, requirements.txt; для Linux fixtures также mss/python-xlib). Проверки не заменяют действия пользователя в аккаунте, native VM и clean-install.
